# Change Log

All notable changes to the "PrincePatelPR26" extension will be documented in this file.

## [0.0.2] - 2026-02-07

### Added

- New PR-Theme Premium variant with softer contrast for long sessions
- New PR-Theme Obsidian variant with a cooler blue-gray accent profile

### Changed

- Renamed the original theme label to PR-Theme Classic for clarity
- Updated extension description to reflect the multi-variant theme pack

## [0.0.1] - 2026-01-30

### Added

- Initial release of PR-Theme, a dark color scheme for Visual Studio Code
- Deep black backgrounds with vibrant green accents
- Comprehensive syntax highlighting for multiple programming languages
- Consistent theming across editor, sidebar, terminal, and UI elements
- Optimized for readability and modern development workflows
